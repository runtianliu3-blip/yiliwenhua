## 播放行为

- 静音、循环、自动播放，滚入视口才播，滚出即暂停（省电、省流量）
- 右下角有一个圆形按钮可以开声音，默认静音
- 系统开启「减弱动态效果」时不自动播放，只显示封面图
- 视频文件缺失时自动隐藏 `<video>`，露出占位底纹并标出 `intro.mp4`

## 压制建议

因为是静音循环的氛围片，不需要高码率：

```bash
ffmpeg -i 原片.mov -vf "scale=1920:-2,fps=25" \
  -c:v libx264 -crf 26 -preset slow -profile:v high -pix_fmt yuv420p \
  -movflags +faststart -an intro.mp4
```

- `-an` 去掉音轨可以再省一半体积。如果要保留开声音的功能，把 `-an` 换成 `-c:a aac -b:a 96k`
- `-movflags +faststart` 让视频边下边播，首帧出得更快
- 想更省，把 `crf` 调到 28 或分辨率降到 1280×720（页面上这块最宽也就 700px 左右）
