# 图片素材清单

把素材按下表的**文件名**放进本目录（`assets/images/`）即可自动生效，不需要改任何代码。

素材未上传时，页面会显示深色渐变占位块并标出所需文件名，布局不会错乱。

共 **43 张**图片 + 视频（见 `../videos/README.md`）。

## 建议

- **格式**：优先 `.webp`（体积小），若改成 webp 需同步修改 HTML 里的 `src` 与 `data-ph`；沿用 `.jpg` 则无需改动。
- **色调**：整站是低饱和暗调 + 暖灰，人物照建议统一做暗调压光，避免明亮跳色。
- **体积**：首屏三张控制在 400KB 以内（满屏铺图），Banner 300KB 以内，卡片 150KB 以内，头像 30KB 以内。
- **人物图**：主体居中偏上，案例卡文字在图**下方**，不压图，所以不需要额外留底部空间。
- **换名字**：想沿用自己的文件名，直接改对应 HTML 里的 `src` 和 `data-ph` 两处即可。
