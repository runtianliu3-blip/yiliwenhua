# 海南以礼文化传媒有限公司 官网

按设计稿实现的静态官网，共 7 个公开页面。纯 HTML + CSS + 原生 JS，无构建步骤，双击 `index.html` 即可预览。

## 本地预览

```bash
cd /path/to/site
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

> 建议用本地服务器而不是直接双击文件：页头/页脚由 JS 注入，`file://` 协议下部分浏览器会拦截。

## 页面

| 文件 | 页面 |
|---|---|
| `index.html` | 首页（全屏照片轮播 + 导语数据实拍 + 四大服务 + 案例 + CTA 卡） |
| `about.html` | 关于我们（机构介绍 + 理念 + 发展历程） |
| `services.html` | 服务项目（四大模块图文交错 + 服务对象） |
| `process.html` | 服务流程（七步交付体系 + 交付物 + FAQ） |
| `cases.html` | 案例中心（分类筛选 + 9 个案例 + 数据总览） |
| `testimonials.html` | 客户评价（6 条评价 + 满意度数据） |
| `contact.html` | 联系我们（联系方式 + 咨询表单 + 到访指引） |

## 目录结构

```
assets/
  css/
    base.css        设计令牌、重置、排版、按钮、图片占位
    layout.css      页头/导航/抽屉、首屏、数据条、内页 Banner、CTA 卡
    components.css  服务卡、案例卡、筛选、关于、流程、案例详情
    pages.css       团队、价格、评价、表单、页脚、返回顶部
    responsive.css  1280 / 1080 / 768 / 420 四档断点
    motion.css      动效层（最后加载，可整文件摘掉不影响布局）
  js/
    layout.js       页头与页脚注入（改导航只需改这一处）
    main.js         滚动、抽屉、入场动画、数字滚动、视差、筛选、视频与表单交互
  images/
    README.md       图片素材清单：文件名、尺寸、比例
  videos/
    README.md       视频素材要求与压制建议
```

## 动效说明

动效集中在 `assets/css/motion.css` + `assets/js/main.js`，包含：

| 位置 | 效果 |
|---|---|
| 页头 | 滚动 40px 后背景转实并模糊 |
| 首屏 | **全屏照片轮播**：3 张满屏图每 6 秒自动切换，1.25s 交叉淡入，当前图 9s 缓慢推镜；**鼠标移入首屏时左右两侧浮现切换箭头**（触屏设备常显），键盘左右键也能切；切到后台标签页自动暂停 |
| 首屏标题 | 逐行遮罩上滑，两行错峰 130ms |
| 导语区 | 右侧视频静音循环播放，滚入视口才播、滚出即停；右下角按钮可开声音 |
| 数据 | 数字从 0 滚动到真实值 |
| 区块入场 | 元素上浮淡入，同组元素按 `data-d` 错峰；图片轻微回落缩放 |
| 按钮 | 悬停时高光斜扫；胶囊按钮箭头右移 |
| CTA 卡 | 7.5s 循环光泽流动 |
| 卡片 | 服务卡图标变金上浮、案例卡图片缓放 + 标题变金、流程行右移 |
| 案例筛选 | 切换时卡片错峰淡入（仅点过筛选后启用） |

**降级**：系统开启「减弱动态效果」（macOS 辅助功能 / Windows 动画设置）时，
`prefers-reduced-motion` 会关掉全部动画与视差，只保留静态版式。
不想要动效时，删掉各页 `motion.css` 那一行即可，布局不受影响。

## 上传素材

把图片按 `assets/images/README.md` 的文件名放进 `assets/images/` 即可，**不需要改代码**。
素材没到位时页面显示占位底纹并标出所需文件名，布局不会错乱。

## 需要注意

- 咨询表单通过 FormSubmit 转发至业务邮箱。首次使用必须在收件邮箱中确认激活；提交失败时会保留用户输入并展示备用联系方式。
- 公开信息变更时，请同步核对电话、微信、地址与案例数据。
- 备案号占位在 `assets/js/layout.js` 的页脚部分。

## 改动指引

- 改导航项 / 页脚内容 → `assets/js/layout.js`
- 改主色、字体、间距 → `assets/css/base.css` 顶部的 `:root`
  - `--f-sans` 中文与正文（苹方/微软雅黑）
  - `--f-num` 数字（无衬线，用于数据、价格、流程序号、电话）
  - `--f-en` 英文小标与面包屑（衬线，仅作点缀）
- 金色主色当前为 `#C9A97C`
- 公司 logo：`assets/images/logo-light.png`（深色页）/ `logo-dark.png`（浅色页）/ `favicon.png`（浏览器标签）
  三个都是从 `素材/公司logo` 抠底生成的，换 logo 时重新生成这三个文件即可，代码不用改
